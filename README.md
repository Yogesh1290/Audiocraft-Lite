# 🎵 AudioCraft Lite

**AI-Powered Music & Audio Generation - Simple, Local, Free**

A lightweight, user-friendly version of Meta's AudioCraft with on-demand model downloads and one-click launcher.

## 🚀 Quick Start (For Users)

### 1. Install Python (One-Time)
Download from: https://www.python.org/downloads/
- ✅ Check "Add Python to PATH" during installation

### 2. Start the App
**Double-click**: `AudioCraft-Lite.bat`

### 3. Create!
- Browser opens automatically
- Choose music or sound effects
- Enter your prompt
- Generate!

## ✨ Features

- 🎹 **MusicGen** - Create full musical compositions
- 🔊 **AudioGen** - Generate sound effects
- ⚡ **Three Quality Levels** - Fast, Balanced, Premium
- 📦 **On-Demand Models** - Download only what you need (NEW!)
- 🎯 **Up to 5 minutes** - Generate long audio
- 💻 **CPU-Friendly** - No GPU required
- 🔒 **Private** - Runs locally, no cloud
- 🆓 **Free & Unlimited** - No subscriptions
- 📦 **One-Click Launch** - Simple to use

---

## 🎯 How It Works

1. **Double-click** `AudioCraft-Lite.bat`
2. **Wait** for browser to open (10-15 min first time)
3. **Choose** music or sound effects
4. **Select** quality level
5. **Describe** what you want
6. **Generate** and enjoy!

## 💡 Tips

### Writing Good Prompts

**Music:**
- ✅ "Upbeat electronic dance music with heavy bass"
- ✅ "Calm acoustic guitar with soft piano"
- ❌ "Nice music"

**Sound Effects:**
- ✅ "Dog barking loudly in a park with birds"
- ✅ "Rain falling on window with distant thunder"
- ❌ "Dog sound"

### Quality Levels
- **Fast** - Quick tests (60-70% quality)
- **Balanced** - Normal use (75-85% quality) ✓ Recommended
- **Premium** - Best quality (90-95% quality)
