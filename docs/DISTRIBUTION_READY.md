STEP 2: Extract Files
  → Right-click the zip file
  → Extract All
  → Choose a location

  → Double-click: AudioCraft-Lite.bat
  → First time: 10-15 minutes (setup)
  → Browser opens automatically

STEP 4: Create Audio
  → Choose: Music or Sound Effects
  → Select: Quality level
  → Enter: What you want to create
  → Click: Generate Audio

STEP 5: Access Files
  → Click "My Files" in the app
  → Or double-click: OPEN_MY_AUDIO_FILES.bat

HELP: See docs/user-guides/START_HERE_SIMPLE.md

==========================================================
