🎯 QUICK START GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  Install Python (one-time)
    → https://www.python.org/downloads/
    → Check "Add Python to PATH"

2️⃣  Double-click: AudioCraft-Lite.bat
    → First time: 10-15 minutes (setup)
    → After that: 10 seconds

3️⃣  Browser opens automatically
    → Start creating music!

4️⃣  To access your files:
    → Click "My Files" button in the app
    → Or double-click: OPEN_MY_AUDIO_FILES.bat
    → Or go to: backend/outputs folder


💡 TIPS FOR NON-TECHNICAL USERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Keep the black window open while using the app
✅ Close the black window to stop the app completely
✅ Download files directly from the browser (easiest)
✅ Or use OPEN_MY_AUDIO_FILES.bat to see all files
✅ First run is slow (downloading AI models)
✅ Subsequent runs are fast (5-10 seconds)


📁 WHERE ARE MY FILES?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option 1: Download from Browser
   → Click "Download" button after generating
   → Saves to your Downloads folder

Option 2: View All Files
   → Click "My Files" button in the app
   → Shows all your generated audio

Option 3: Use Batch File
   → Double-click: OPEN_MY_AUDIO_FILES.bat
   → Opens folder with all your files

Option 4: Manual Access
   → Open: backend/outputs folder
   → All .wav files are there
