# 🎵 AudioCraft Lite - Start Here (Simple Guide)

## For Non-Technical Users

This guide is for people who **don't know coding** and just want to use the app!

---

## 📋 What You Need (One-Time)

### 1. Install Python (5 minutes)

**What is Python?** It's a free program that runs the app.

**How to install:**
1. Go to: https://www.python.org/downloads/
2. Click the big yellow "Download Python" button
3. Run the downloaded file
4. **IMPORTANT**: Check the box that says "Add Python to PATH"
5. Click "Install Now"
6. Wait for it to finish
7. Done!

### 2. Install Node.js (Optional, 5 minutes)

**What is Node.js?** It helps build the user interface.

**How to install:**
1. Go to: https://nodejs.org/
2. Click "Download" (the LTS version)
3. Run the downloaded file
4. Click "Next" through all steps
5. Done!

**Note:** If you skip this, the app will still work if the interface is already built.

---

## 🚀 How to Use (Every Time)

### Step 1: Find the App

1. Open the folder where you extracted AudioCraft Lite
2. Look for a file called: **`AudioCraft-Lite.bat`**

### Step 2: Start the App

1. **Double-click** `AudioCraft-Lite.bat`
2. A black window will open (this is normal!)
3. Wait 5-10 seconds
4. Your web browser will open automatically
5. Done! You can now use the app!

### Step 3: Use the App

1. Choose what you want to create:
   - **MusicGen** = Music
   - **AudioGen** = Sound effects

2. Choose quality:
   - **Fast** = Quick but lower quality
   - **Balanced** = Good quality (recommended)
   - **Premium** = Best quality but slower

3. Type what you want to create:
   - Example: "Calm piano music"
   - Example: "Dog barking sound"

4. Click "Generate Audio"

5. Wait for it to finish

6. Listen and download!

### Step 4: Stop the App

**To close the app:**
- Close the black window (the one that opened first)
- OR press Ctrl+C in the black window

**Important:** The app will stop completely. No hidden processes will keep running!

## ❓ Common Questions

### Q: What is the black window?
**A:** That's the app running. Keep it open! Close it to stop the app.

### Q: Is it safe?
**A:** Yes! It's open source and runs only on your computer. No data is sent anywhere.

### Q: Do I need internet?
**A:** Only for the first run (to download AI models). After that, it works offline!

### Q: Where are my files saved?
**A:** Your generated audio files are automatically saved. To access them:

**Option 1: Download from Browser (Easiest)**
- After generating audio, click the "Download" button
- File saves to your Downloads folder

**Option 2: View All Files**
- Click the "My Files" button in the app (top right of Examples section)
- Opens a page showing all your generated files
- Or double-click `OPEN_MY_AUDIO_FILES.bat` in the main folder

**Option 3: Manual Access**
- Open the AudioCraft Lite folder
- Go to: `backend` → `outputs`
- All your audio files are there!

### Q: How do I close it completely?
**A:** Just close the black window. Everything stops. No background processes!

### Q: Will it slow down my computer?
**A:** Only while generating audio. Otherwise, it uses minimal resources.

### Q: Can I use it without the black window?
**A:** No, the black window is the server. It must stay open.
