## 🚀 How to Use

### Start Backend
```bash
cd audiocraft-lite/backend
python main.py
```
Runs on: http://localhost:8000

### Start Frontend
```bash
cd audiocraft-lite/frontend
npm start
```
Opens at: http://localhost:3000

### Generate Audio
1. Select quality level (Fast/Balanced/Premium)
2. Choose mode (MusicGen/AudioGen)
3. Enter your prompt
4. Adjust settings (optional)
5. Click "Generate Audio"
6. Download your creation!
